# Positioning Validation Kit — CipherExam

**Created:** 2026-05-30 · **Owner:** Dave · **Status:** ready to run

## Why this exists

Code Q board diagnosis: **~0 users = the offer or the category frame isn't landing.** When nobody buys, it's almost never the product — it's that the offer isn't compelling enough, or buyers are putting CipherExam on the wrong mental shelf (comparing it to free Quizlet decks instead of $400 instructor-led PMP boot camps).

The board's prescription is **don't build — test.** Five 20-minute conversations cost a day. A quarter of feature work costs a quarter. Validate positioning before scaling code.

This kit is everything you need to run that test this week.

## The two frameworks behind it

- **Hormozi — Grand Slam Offer.** Four levers: Dream Outcome ↑, Perceived Likelihood ↑, Time Delay ↓, Effort & Sacrifice ↓. Crank value up, crank cost-in-time-and-pain down until the offer is irrational to refuse. → `01-one-pager.md`, top half.
- **Dunford — Category Frame.** Where do you sit in the buyer's head? "AI flashcard app" → competes with Quizlet, price ≈ $0. "AI cert tutor that finds your weak spots before the exam does" → competes with prep courses, price $50–400. Same product, totally different willingness to pay. → `01-one-pager.md`, bottom half.

## The files

| File | What it is | When you use it |
|---|---|---|
| `01-one-pager.md` | The offer + category frame on one page (3 frame candidates to test) | Read it to the prospect / share screen on the call |
| `02-interview-script.md` | The 20-min call script — same questions every time | During each call |
| `03-outreach.md` | Copy-paste DMs/comments to book 5 PMP candidates | This week, to fill the calendar |
| `04-decision-rubric.md` | Keep frame / pivot frame / pivot offer — decide from what you hear | After all 5 calls |
| `05-call-log.md` | One block per call — capture their exact words | Fill in live during/after each call |

## Run of show (1 week)

1. **Today:** read `01-one-pager.md`. Pick the ONE category frame you'll lead with (or test all 3 — see the file).
2. **Today–Day 2:** post/DM from `03-outreach.md`. Target: book 5 calls with **real PMP candidates** — people sitting the exam in the next 1–3 months. Not friends. Not other founders.
3. **Day 2–6:** run the calls with `02-interview-script.md`. Log each in `05-call-log.md` in their words, not your paraphrase.
4. **Day 7:** score against `04-decision-rubric.md`. Decide: keep frame / pivot frame / pivot offer. Their words become the next draft of the homepage H1 and the PMP LP.

## The three things you're listening for (and nothing else)

1. **Do they get it in 10 seconds?** (frame clarity)
2. **Do they ask "how much?" before you mention price?** (pull — they've shelved you with paid prep, not free apps)
3. **Do they push back on price, or on relevance?** Price pushback = offer problem. Relevance pushback ("isn't this just another question bank?") = frame problem.

## Guardrails (from the brand context — do not break)

- **PMP first.** It's priority #1 — clearest message, biggest market. Run the whole test on PMP candidates. Don't dilute across certs.
- **Real offer only.** Starter $0, Pro $19/mo (or $189/yr, saves 17%), 7-day free trial, no credit card, cancel anytime. No invented lifetime tier, no scarcity caps, no "first 500."
- **No "guaranteed pass."** Legal + credibility risk, and it's the lazy competitor move. Our edge is *reasoning*, not a refund promise.
- **You did not sit the PMP.** Don't fake first-person exam-taking ("when I sat for it…"). You built the tool; speak as the builder.
