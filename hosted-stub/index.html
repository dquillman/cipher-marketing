Cipher Marketing runs locally

There is one dashboard. It is not this URL.

Start it, then open http://localhost:8766/app.html:

cd "G:\Users\daveq\cipher-marketing"
node serve.mjs

This address used to serve a copy of the dashboard that could never load any posts. Firebase Hosting deliberately does not deploy data/, because posts.json holds unpublished drafts, live metrics and campaign strategy — none of which belongs on a public URL. So the hosted copy showed the navigation, the version badge and an empty pipeline, which looked like a broken dashboard rather than an absent one. It has been retired so there is exactly one real app.

A hosted dashboard would need an authenticated API reading Firestore rather than a local JSON file. Worth building if you want it on your phone; not worth faking.
